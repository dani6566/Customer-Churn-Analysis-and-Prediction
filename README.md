# Customer Churn Analysis and Prediction

This project analyzes customer churn behavior in a telecommunications company and builds predictive models to identify at-risk customers. The goal is to provide actionable insights to reduce churn and improve customer retention.

---
## Key Features

- Clean and modular codebase
- Exploratory data analysis with visualizations
- Customer segmentation by tenure, charges, and contract
- Predictive modeling using Logistic Regression and Decision Tree
- Model evaluation with precision, recall, F1-score, and ROC-AUC
- Business recommendations based on data insights
